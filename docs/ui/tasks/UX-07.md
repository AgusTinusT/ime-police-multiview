# UX-07 — Panel Admin: layout sidebar (pola dasar)

**Prioritas:** 🟠 P1 · **Estimasi:** menengah · **Bergantung:** —
**Commit:** `feat(ui): UX-07 admin sidebar layout`
> Gemini membuat pola dasar. Setelah status 🟣, **Claude** memoles (grup menu, badge antrian, section Ringkasan, HP). Gemini **tidak** mengerjakan bagian poles.

## Konteks
`/admin/officers` (`Pages/Admin/OfficerManagement.vue`) memakai 9 tab horizontal di bawah header publik. Ganti menjadi layout admin standar: sidebar kiri + konten kanan. **Tampilan berubah, perilaku tidak**: isi setiap tab (komponen di `Components/Admin/*`) dipakai apa adanya.

## File (hanya ini)
- `resources/js/Components/ui/sidebar/*` — **hanya** lewat `npx shadcn-vue@latest add sidebar` (jangan diedit manual)
- `resources/js/Layouts/AdminLayout.vue` (baru)
- `resources/js/Pages/Admin/OfficerManagement.vue`

## Yang harus dilakukan
1. Pasang komponen Sidebar shadcn-vue via CLI. Token `--color-sidebar*` sudah ada di `app.css`; jangan menambah token.
2. `AdminLayout.vue`: `SidebarProvider` + `Sidebar` (`collapsible="icon"`) + `SidebarInset`. Header konten: `SidebarTrigger`, judul section aktif (slot/prop), dan link "Kembali ke situs" (`Link href="/"`). Tanpa `TacticalDashboardHeader`/footer publik.
3. Menu sidebar = **daftar tab yang sudah ada saat ini, urutan sama** (satu `SidebarMenuItem` per tab, ikon `@lucide/vue`). Belum perlu grup atau badge.
4. `OfficerManagement.vue`: bungkus dengan `AdminLayout`; ganti komponen `Tabs` horizontal dengan state `activeTab` yang dibaca/ditulis ke query `?tab=` (`router.get(url, {}, { preserveState: true, preserveScroll: true, replace: true })` atau `history.replaceState`). Default = tab pertama saat ini. Konten tiap tab dirender seperti sebelumnya.
5. Jangan mengubah `Components/Admin/*`, controller, route, atau API.

## Selesai jika
- [ ] Semua tab lama bisa dibuka dari sidebar dan berfungsi seperti sebelumnya; `?tab=` bisa di-bookmark & tombol Back bekerja.
- [ ] Di 390px sidebar menjadi drawer (bawaan shadcn); tidak ada scroll horizontal halaman.
- [ ] `npm run lint:ui` = 0 untuk `AdminLayout.vue` & `OfficerManagement.vue`; `php artisan test --filter=UiKitRouteTest` dan `npm run build` sukses.
