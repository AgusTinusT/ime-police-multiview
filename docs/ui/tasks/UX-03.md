# UX-03 — Bersihkan peringatan ESLint di header & footer

**Prioritas:** 🟢 P3 · **Estimasi:** sangat kecil · **Bergantung:** —
**Commit:** `refactor(ui): UX-03 hapus variabel tak terpakai`

## File
- `resources/js/Components/TacticalDashboardHeader.vue`
- `resources/js/Components/TacticalFooter.vue`

## Yang harus dilakukan
1. Jalankan `npx eslint resources/js/Components/TacticalDashboardHeader.vue resources/js/Components/TacticalFooter.vue`.
2. Hapus variabel tak terpakai yang dilaporkan (`emit` di header, `t` di footer) **hanya jika** memang tidak dipakai di template maupun script. Jika `emit` dihapus, `defineEmits` tetap boleh ada bila parent memasang listener — cukup jangan menyimpannya ke variabel.
3. Jangan mengubah hal lain.

## Selesai jika
- [ ] ESLint 0 peringatan untuk kedua file; `npm run build` sukses.
