## Spesifikasi
**Props `HeroCarousel`:** `slides` (array dari prop `heroSlides`), `interval` (default 7000), `preview` (bool, untuk HS-02: tanpa autoplay & tanpa telemetri).

**Tata letak slide (`HeroSlide`):**
- Tinggi tetap: `h-[420px] sm:h-[460px] lg:h-[520px]` (**satu-satunya** ukuran arbitrer yang diizinkan; beri komentar `/* hero height token */`). Gambar `object-cover` + gradient `from-bg via-bg/70 to-transparent` dari kiri agar teks terbaca.
- `<picture>`: `<source media="(max-width: 640px)" :srcset="image_mobile_url">` + `<img :src="image_desktop_url" :alt="image_alt">`. Slide index 0: `loading="eager" fetchpriority="high"`; lainnya `loading="lazy"`.
- Konten di dalam `PageContainer`: `Badge` (aksen slide) → judul `font-heading text-4xl lg:text-6xl font-bold text-foreground` → subjudul `text-base text-muted-foreground` → `Button` (default) + `Button variant="outline"` (pakai `as-child` + `Link`/`a`).
- Bingkai slide: `TacticalFrame variant="hero"` dengan `accent` = `accent` slide (+ `.hud-corners` opsional) — ini satu-satunya aksen taktis di hero.
- `live_spotlight`: `OfficerAvatar live` + `LiveBadge :viewers`, judul stream.
- Aksen slide = garis/ glow memakai token (`accent` → `border-{accent}` / `shadow-glow-*`).

**Perilaku:**
- Autoplay `interval` ms; **pause** saat `mouseenter`, saat fokus di dalam hero (`focusin`/`focusout`), saat `document.visibilityState !== 'visible'`, dan bila `matchMedia('(prefers-reduced-motion: reduce)')`.
- Tombol pause/play terlihat (`aria-label`).
- **Fondasi:** komponen shadcn-vue `Carousel` (Embla) + plugin `embla-carousel-autoplay` (`npm i embla-carousel-autoplay`); autoplay dikendalikan lewat API plugin (`stop`/`play`/`reset`) sesuai aturan pause di bawah.
- Prev/next (`CarouselPrevious`/`CarouselNext` atau `Button variant="ghost" size="icon"` + `ChevronLeft`/`ChevronRight`), titik indikator (tombol `aria-label="Slide 2 dari 5"`, `aria-current`), progress bar tipis yang berjalan sesuai interval.
- Swipe: bawaan Embla.
- Panah kiri/kanan saat hero fokus.
- Transisi: fade + geser 200ms `motion-safe` saja.
- 1 slide → tanpa navigasi & autoplay. 0 slide → komponen tidak dirender; **Dashboard menampilkan hero statis lama** (fallback, jangan dihapus).
- A11y: wrapper `role="region" aria-roledescription="carousel" aria-label="Sorotan"`; tiap slide `role="group" aria-roledescription="slide" :aria-label="`${i+1} dari ${n}`"`, slide tak aktif `aria-hidden="true"` + `inert`.

**Telemetri (bukan saat `preview`):**
- Impression: slide aktif tampil ≥1 detik dan hero terlihat (`IntersectionObserver` ≥50%) → `navigator.sendBeacon('/api/v1/hero-slides/{id}/event', blob {type:'impression'})`, sekali per sesi per slide (`sessionStorage`, dibungkus try/catch).
- Klik CTA → beacon `{type:'click'}` lalu navigasi normal. Slide `live_spotlight` tidak punya id DB → tanpa telemetri.
