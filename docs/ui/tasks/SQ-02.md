## Yang harus dilakukan
1. **Membuka squad di Multiview:** `?squad={slug}` → `GET /api/v1/squads/{slug}` → pilih stream live milik anggotanya (cocokkan `stream.officer.id` dengan `officers[].id`). Mode Grid/Fokus: semua anggota yang live jadi POV. Mode Solo: POV pertama yang live diputar, strip **hanya** berisi anggota squad yang live (tambahkan prop opsional `allowedOfficerIds` ke strip **tanpa** mengubah perilaku lainnya). Anggota tidak live → `toast` "N anggota squad sedang offline". Tidak ada yang live → pesan kosong + tetap tampilkan nama squad.
2. **`SquadMenu`** (DropdownMenu, ikon `Users`): judul squad aktif (jika ada); daftar "Squad saya" (`GET /mine`, hanya saat login) → klik membuka squad; item "Simpan POV ini sebagai squad" → `SquadSaveDialog`; item "Keluar dari squad" saat squad aktif. Tamu: item "Masuk untuk membuat squad" (buka modal auth yang sudah ada, `AuthModal`).
3. **`SquadSaveDialog`:** nama, deskripsi opsional, visibilitas (Pribadi/Publik), daftar officer dari POV yang sedang dipilih (bisa dihapus satu per satu). Simpan → `POST /` (atau `PUT` bila sedang mengedit squad milik sendiri). Squad milik orang lain → tombol "Fork & edit" (`POST /{id}/fork`) lalu buka dialog untuk salinan baru. Error 422 tampil di bawah field.
4. **Dashboard:** `CatalogRow` "Squad komunitas" setelah baris "Sedang live", data `GET /public` (fetch saat mount; kosong/gagal → baris disembunyikan). `SquadCatalogCard`: nama, pemilik, tumpukan avatar anggota (maks 5 + "+N"), `LiveBadge` dengan `live_count` jika > 0, jumlah fork; klik → `/multiview?squad={slug}`; tombol "Fork" (perlu login) → `POST fork` → toast + buka multiview squad hasil fork.
5. Jangan mengubah file di luar daftar; jangan mengubah API SQ-01.
