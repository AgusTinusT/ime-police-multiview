# HS-01 — Backend Hero Slider (tabel, model, API admin, data dashboard)

**Prioritas:** 🟠 P1 · **Estimasi:** sedang · **Bergantung:** — (boleh paralel dengan DS-01/02)
**Commit:** `feat(hero): HS-01 hero slides backend`
**Referensi:** `docs/hero-slider/PRD.md` §3–§6 dan §8.

## 1. Migration & Model
- Tabel `hero_slides` sesuai PRD §4 (enum `slide_type`, `accent`, `audience`; FK `created_by`/`updated_by` → users `nullOnDelete`; index `is_active, sort_order`).
- Tabel `hero_slide_stats` (`hero_slide_id` FK cascade, `stat_date` date, `impressions`/`clicks` unsigned int default 0, unique `hero_slide_id+stat_date`).
- Model `HeroSlide` (fillable, casts datetime/bool, accessor `image_desktop_url`/`image_mobile_url` via `Storage::disk('public')->url()`), `HeroSlideStat`.

## 2. Service `App\Services\HeroSlideService`
- `forAudience(?User $user): array` → slide aktif, `starts_at <= now` (atau null), `ends_at > now` (atau null), cocok audiens (`guest` bila belum login, `officer` bila `$user?->officer`, `member` bila login non-officer, `all` selalu), urut `sort_order`, maks. 5. Cache `Cache::remember("hero_slides:{$audience}", 60, ...)`.
- `live_spotlight`: isi otomatis dari `ActiveStream` LIVE milik officer aktif dengan **`viewers_count` terbesar** (kolom bernama `viewers_count`, bukan `viewer_count`): judul = nama officer, subjudul = judul stream, gambar = `thumbnail_url`, CTA utama → `/multiview`, CTA kedua → `/@{slug}` bila punya bio. Tidak ada yang live → slide dibuang.
- `forget()`: hapus 4 key cache audiens.
- Output dipetakan ke array ringkas (id, type, title, subtitle, badge_label, accent, image_desktop_url, image_mobile_url, image_alt, cta_primary{label,url}, cta_secondary{label,url}, live{…} bila spotlight).

## 3. Upload gambar
- `App\Services\HeroImageService::store(UploadedFile $file, string $variant): string` — validasi mime `jpg,jpeg,png,webp`, maks. 2048 KB, dimensi min (desktop 1600×600, mobile 1080×1080); re-encode ke WebP kualitas 82 dengan **GD** (`imagecreatefromstring` → `imagewebp`), nama acak, simpan `hero/{uuid}.webp` di disk `public`. Hapus file lama saat diganti/slide dihapus.

## 4. API admin (`auth`, `admin`, prefix `api/v1/admin/hero-slides`) — controller `HeroSlideController`
`index`, `store` (multipart), `update` (POST multipart + `_method=PUT`), `destroy`, `toggle`, `reorder` (`ordered_ids` lengkap & distinct, transaksi) — sesuai PRD §8.
- Validasi PRD §5: URL CTA = path diawali `/` (bukan `//`) atau `https://`; `ends_at` after `starts_at`; `title` wajib kecuali `live_spotlight`; gambar desktop wajib kecuali `live_spotlight`; `image_alt` wajib bila ada gambar; maks. satu `live_spotlight` aktif.
- `index` menyertakan impressions & clicks 7 hari terakhir per slide.
- Setiap aksi → `AuditLogger::log('hero_slide.created|updated|deleted|toggled|reordered', 'hero_slide', $id, ...)` dan `HeroSlideService::forget()`.

## 5. Endpoint telemetri publik
`POST /api/v1/hero-slides/{slide}/event` `{type: impression|click}` — `throttle:60,1`, tidak butuh login, tulis langsung ke `hero_slide_stats` (`firstOrCreate` baris hari ini + `increment`; volume kecil, tidak perlu cache/flush). Slide nonaktif → 404. Respons 204. Daftarkan di luar grup `auth` dan kecualikan dari CSRF bila `sendBeacon` tidak membawa token (`bootstrap/app.php` → `validateCsrfTokens(except: ['api/v1/hero-slides/*/event'])`).

## 6. Dashboard
`PoliceCommandController::dashboard` → tambah prop `heroSlides => HeroSlideService::forAudience($request->user())`.
