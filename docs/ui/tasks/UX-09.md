# UX-09 — Admin: tabel Daftar Perwira lebih ringkas + panel detail (pola dasar)

**Prioritas:** 🟠 P1 · **Estimasi:** menengah · **Bergantung:** UX-07
**Commit:** `refactor(ui): UX-09 tabel perwira ringkas + sheet detail`
> Gemini membuat pola dasar. Poles visual akhir (kepadatan, urutan info, tampilan HP) oleh **Claude**. **Tampilan berubah, perilaku tidak**: semua aksi & fungsi lama tetap ada.

## Konteks
Tabel di tab `officers` (`Pages/Admin/OfficerManagement.vue`) memiliki 9 kolom dan beberapa tombol aksi di dalam sel (atur duty, hashtag bypass, status), sehingga terlalu padat.

## File (hanya ini)
- `resources/js/Pages/Admin/OfficerManagement.vue` — hanya blok tabel tab `officers`
- `resources/js/Components/Admin/OfficerDetailSheet.vue` (baru)

## Yang harus dilakukan
1. Kurangi tabel desktop menjadi **5 kolom**:
   | Kolom | Isi |
   | :--- | :--- |
   | **Perwira** | `OfficerAvatar` + nama (semibold) + baris kecil `text-xs text-muted-foreground`: callsign · `DeptBadge` · rank |
   | **Status** | `LiveBadge` jika live, selain itu `Badge variant="secondary"` "10-7"; `Switch` aktif/nonaktif (memanggil `toggleOfficerStatus` yang sama) |
   | **Duty bulan ini** | total jam ringkas (mis. `12j 30m`), `font-mono text-sm` |
   | **Akun** | ikon `Link2` hijau (`text-success`) + slug jika terikat, `text-muted-foreground` "—" jika belum |
   | **Aksi** | `DropdownMenu` yang sudah ada (tetap), **tambahkan** item "Detail" di paling atas dan item "Hashtag bypass: ON/OFF" (memanggil `toggleHashtagBypass`) |
2. Klik baris (kecuali Switch & tombol aksi: pakai `@click.stop`) membuka `OfficerDetailSheet` (`Sheet side="right"`, `sm:max-w-md`). Isi sheet, dikelompokkan dengan `SectionHeader` kecil / `Separator`:
   - **Identitas:** avatar besar, nama, rank, agency, divisi, callsign, nomor badge.
   - **Duty:** total jam bulan ini, rata-rata, tombol "Atur jam duty" (`openDutyModal`), status hashtag rule + tombol toggle (`toggleHashtagBypass`).
   - **Sertifikasi:** daftar `Badge` sertifikasi (data yang sama dengan kolom lama).
   - **YouTube & akun:** handle (link), akun terikat, slug, status bio; tombol yang sama dengan menu (`openBindModal`, `openSlugModal`, `openUnbindModal`).
   - Footer: `Button variant="outline"` "Edit" (`openEditModal`) dan `Button variant="destructive"` "Hapus" (`confirmDeleteOfficer`).
3. Sheet menerima `officer` (prop) dan meng-emit event yang dipetakan ke fungsi lama di halaman — **jangan** memindahkan logika API ke sheet.
4. Jangan mengubah kolom pencarian/filter, tombol sinkronisasi, modal yang sudah ada, controller, atau API.
