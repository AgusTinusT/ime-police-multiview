# UX-06 — Top 10 tetap tampil di awal bulan (fallback bulan lalu) — backend

**Prioritas:** 🟡 P2 · **Estimasi:** kecil–menengah · **Bergantung:** —
**Commit:** `feat(ui): UX-06 leaderboard fallback bulan lalu`

## Konteks
Baris katalog "Top 10 patroli bulan ini" di Dashboard hanya menampilkan officer dengan `total_hours_num > 0`. Di awal bulan semuanya 0, sehingga baris (dan section Top Streamer) terlihat kosong.

## File
- `app/Http/Controllers/PoliceCommandController.php` — hanya `getMonthlyLeaderboard()`
- `resources/js/Pages/Dashboard.vue` — hanya judul baris Top 10
- Test baru: `tests/Feature/LeaderboardFallbackTest.php`

## Yang harus dilakukan
1. Di `getMonthlyLeaderboard()`: jika tidak ada officer dengan jam > 0 bulan ini, hitung untuk **bulan sebelumnya** dengan logika yang sama, dan tambahkan kunci `is_previous_period: true` serta `period_text` bulan tersebut. Jika bulan ini ada data, `is_previous_period: false`. Bentuk data lain tidak berubah.
2. Dashboard: judul baris menjadi `Top 10 patroli bulan lalu` jika `monthlyLeaderboard.is_previous_period`, selain itu tetap `Top 10 patroli bulan ini`.
3. Test: (a) ada jam bulan ini → `is_previous_period` false; (b) bulan ini kosong, bulan lalu ada → true dan berisi data bulan lalu.
