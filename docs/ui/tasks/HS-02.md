# HS-02 — Panel Admin "Hero Slides"

**Prioritas:** 🟠 P1 · **Estimasi:** sedang (frontend) · **Bergantung:** HS-01, DS-02
**Commit:** `feat(hero): HS-02 admin hero slides tab`
**Referensi:** `docs/hero-slider/PRD.md` §7 dan `docs/design-system/GEMINI-UI-PLAYBOOK.md`. Semua UI memakai komponen `@/Components/ui/*` & `@/Components/tactical/*` (lolos `npm run lint:ui`).
**Padanan komponen:** daftar → `Table`; badge → `Badge` (`warning`/`success`/`secondary`); toggle → `Switch`; form → `Dialog` + `Input`/`Textarea`/`Select`/`Switch`/`Label`; hapus → `AlertDialog`; toast → `toast()` Sonner; ikon → `lucide-vue-next` (`GripVertical`, `Pencil`, `Copy`, `Trash2`).

## File
- `resources/js/Pages/Admin/OfficerManagement.vue` — tambah tab `hero` (pola tombol `@click="activeTab = '...'"` seperti tab `announcements`).
- Komponen baru `resources/js/Components/Admin/HeroSlidesTab.vue` dan `resources/js/Components/Admin/HeroSlideForm.vue`.

## Yang harus dilakukan
1. **Daftar slide** (`GET /api/v1/admin/hero-slides`): thumbnail, judul, `Badge` tipe & audiens, status jadwal (*Terjadwal* = warning, *Tayang* = success, *Berakhir* = neutral, *Nonaktif* = neutral), impressions/klik 7 hari, toggle aktif (`BaseToggle`), tombol Ubah / Duplikat / Hapus (konfirmasi `BaseModal`).
2. **Urutan drag & drop** (HTML5 drag events, tanpa library) → `POST /reorder`.
3. **Form** (`Dialog` dengan `DialogContent class="sm:max-w-3xl"` berisi `HeroSlideForm`):
   - Field PRD §4 dengan `Input`/`Select`/`Textarea`/`Switch` + `Label`; field gambar & judul disembunyikan untuk `live_spotlight`.
   - Unggah gambar desktop & mobile (`input type=file accept="image/jpeg,image/png,image/webp"`) dengan pratinjau `URL.createObjectURL`, info ukuran minimum.
   - Kirim `FormData` (update: `_method=PUT`).
   - Error 422 tampil di bawah field terkait.
4. **Pratinjau langsung** di sisi form: render `HeroCarousel` (dari HS-03) dengan satu slide hasil form, tombol toggle *Desktop / Mobile* (lebar kontainer 100% / 390px). *Jika HS-03 belum selesai, tampilkan pratinjau sederhana dan tandai di Dev Notes; lengkapi setelah HS-03.*
5. Toast sukses/gagal memakai pola `showToast` yang ada.

## Uji
- `npm run build` + `npm run lint:ui` lolos.
- Uji manual: buat slide terjadwal, ubah urutan, nonaktifkan, hapus — cek tampil/hilang di dashboard. Catat di Dev Notes.
