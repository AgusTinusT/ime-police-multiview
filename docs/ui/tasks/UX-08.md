# UX-08 — Gabungkan baris per departemen menjadi satu baris dengan chip filter

**Prioritas:** 🟠 P1 · **Estimasi:** kecil · **Bergantung:** —
**Commit:** `feat(ui): UX-08 satu baris patroli per departemen`

## Konteks
Di produksi rata-rata ±5 live per departemen (LSPD bisa >10). Empat baris "Patroli LSPD/BCSO/SASP/SAPR" di Dashboard jadi pendek dan sering kosong; departemen tanpa live hilang begitu saja.

## File (hanya ini)
- `resources/js/Pages/Dashboard.vue` — hanya bagian `deptRows` dan `<CatalogRow v-for="r in deptRows" …>`
- `resources/js/locales/id.json`, `resources/js/locales/en.json` — kunci baru di grup `catalog`

## Yang harus dilakukan
1. Ganti `v-for` empat baris menjadi **satu** `<CatalogRow :title="$t('catalog.patrol_by_dept')">` ("Patroli per departemen").
2. Di slot `#action` (atau tepat di bawah judul), tampilkan 4 chip `Button size="xs"` (`variant="default"` untuk yang aktif, `secondary` lainnya) berisi `{DEPT} {jumlah}` untuk LSPD, BCSO, SASP, SAPR — **selalu tampil**, termasuk yang 0.
3. State `activeDept` default = departemen dengan live terbanyak (saat seri, urutan LSPD→BCSO→SASP→SAPR). Kartu = `CatalogCard` yang sama seperti sekarang untuk departemen aktif.
4. Jika departemen aktif 0 live: tampilkan satu kartu kosong sederhana di dalam baris (`text-sm text-muted-foreground`, mis. "Belum ada unit {dept} yang live") — baris tidak disembunyikan. Sembunyikan baris hanya jika **semua** departemen 0.
5. Jangan mengubah baris lain, `CatalogCard`, atau `CatalogRow`.

## Selesai jika
- [ ] Satu baris dengan 4 chip; ganti chip mengganti kartu tanpa reload; chip 0 tetap bisa dipilih.
- [ ] Teks baru lewat i18n (id & en).
- [ ] `npm run lint:ui -- resources/js/Pages/Dashboard.vue` = 0; `npm run build` sukses.
