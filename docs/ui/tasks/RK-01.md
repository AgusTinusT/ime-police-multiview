# RK-01 — Halaman Ranking (pola dasar)

**Prioritas:** 🟠 P1 · **Estimasi:** menengah · **Bergantung:** UX-06
**Commit:** `feat(ranking): RK-01 halaman ranking`
> Gemini membuat pola dasar yang berfungsi. Poles visual akhir oleh **Claude**. Komponen UI kit saja (`Tabs`, `Table`, `Card`, `OfficerAvatar`, `DeptBadge`, `LiveBadge`, `Progress`, `PageContainer`, `PageHeader`).

## Konteks
Direktori Perwira (`/officers`) kini diurutkan berdasarkan pangkat. Semua urutan "prestasi" (jam patroli, subscriber, dll.) dipindah ke halaman baru **`/ranking`**.

## File (hanya ini)
- `routes/web.php` — `Route::get('/ranking', [PoliceCommandController::class, 'rankingPage'])->name('ranking');`
- `app/Http/Controllers/PoliceCommandController.php` — method baru `rankingPage()`
- `resources/js/Pages/Ranking.vue` (baru)
- `resources/js/Components/TacticalDashboardHeader.vue` & `TacticalMobileBottomNav.vue` — tambah 1 tautan "Ranking" (setelah "Direktori Perwira")
- `resources/js/Pages/OfficerDirectory.vue` — hanya: hapus opsi urutan `subs_desc` & `subs_asc` (sisakan `rank` & `name`), ubah klik StatTile "Target <1K Subs" agar membuka `/ranking?tab=road_to_1k`, dan tambah tombol `Link` "Lihat ranking" di dekat pilihan urutan
- `resources/js/locales/id.json`, `en.json` — grup `ranking`
- `tests/Feature/RankingPageTest.php` (baru)

## Data (`rankingPage()` → Inertia `Ranking`)
Satu prop `ranking` berisi lima daftar (officer aktif saja, masing-masing maks. 50, tiap item: `id, officer_name, callsign, department, rank (rank_title ?? rank), avatar_url, is_live, youtube_url, value, value_label`):
| Kunci | Urutan | `value` / `value_label` |
| :--- | :--- | :--- |
| `duty_month` | `monthly_duty_minutes` desc (hanya > 0) | menit / "12 Jam 30m" |
| `duty_last_month` | `previous_monthly_duty_minutes` desc (hanya > 0) | menit / "12 Jam 30m" |
| `subscribers` | `subscriber_count` desc | angka / "12,3 rb" |
| `road_to_1k` | `subscriber_count` < 1000, desc (paling dekat 1K dulu) | angka / "736/1.000" |
| `recently_on_duty` | `last_duty_at` desc (tidak null) | timestamp ISO / "2 jam lalu" (pakai `diffForHumans()` locale `id`) |

Plus `period_text` (bulan ini & bulan lalu, format "OKTOBER 2026"). `is_live` = punya `activeStream` (eager load). Pakai eager loading (`rankRelation`, `activeStream`), tanpa N+1.

## UI (`Ranking.vue`)
1. `TacticalLayout` + `PageContainer` + `PageHeader` (judul "Ranking Perwira", subjudul singkat).
2. `Tabs` untuk lima daftar; tab aktif disimpan di `?tab=` (default `duty_month`).
3. Isi tab: **podium 3 teratas** (3 `Card`, peringkat 1 di tengah & sedikit lebih tinggi) lalu `Table` untuk peringkat 4+ (kolom: #, Perwira [avatar + nama + callsign + `DeptBadge`], nilai). `LiveBadge` di samping nama yang sedang live. Tab `road_to_1k`: kolom nilai berisi `Progress` + teks.
4. Daftar kosong → `EmptyState` (mis. "Belum ada jam patroli bulan ini").
5. Di HP (< 640px): tabel diganti daftar kartu ringkas; tab bisa digeser horizontal.
