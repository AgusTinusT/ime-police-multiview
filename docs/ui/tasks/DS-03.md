**Prioritas:** 🟠 P1 · **Estimasi:** sedang · **Bergantung:** DS-02
**Commit dipecah:** `feat(ui): DS-03a ui kit catalog` → `chore(ui): DS-03b lint:ui checker`

## DS-03a — Katalog hidup
- Route `GET /dev/ui-kit` di grup `['auth', 'admin']` → `Inertia::render('Dev/UiKit')`.
- `resources/js/Pages/Dev/UiKit.vue` (pakai `PageContainer` + `PageHeader`), section:
  1. **Token warna** — swatch setiap token README §2.1–2.2 + nama kelas.
  2. **Tipografi** — setiap peran README §2.3 dengan contoh kalimat Indonesia.
  3. **Komponen shadcn** — setiap komponen DS-02a dengan semua variant/size (Button, Badge termasuk `success/warning/info/live`, Card, form lengkap, Dialog, AlertDialog, Sheet, DropdownMenu, Tooltip, Tabs, Table, Avatar, Skeleton, Alert, Empty, Pagination, toast demo).
  4. **Komponen taktis** — PageHeader, SectionHeader, TacticalFrame (3 variant × 3 accent), LiveBadge, DeptBadge (4 dept), StatTile, OfficerAvatar (live/non-live), EmptyState, contoh `.hud-grid`/`.hud-corners`.
  5. Setiap contoh disertai potongan kode (`<pre><code>` teks statis).
- Halaman ini sendiri wajib lolos `lint:ui`.

## DS-03b — Pemeriksa gaya `scripts/lint-ui.mjs`
`package.json` → `"lint:ui": "node scripts/lint-ui.mjs"`. Tanpa dependensi baru.
- **Target:** argumen file/folder bila diberikan (`npm run lint:ui -- resources/js/Pages/Dashboard.vue`); tanpa argumen → file `.vue` yang berubah dibanding `main` + perubahan belum di-commit. Opsi `--all` (semua file) dan `--report` (exit 0, cetak ringkasan per file — untuk mengukur sisa utang).
- **Abaikan** folder `resources/js/Components/ui/` dan isi blok `<pre>` di `Pages/Dev/`.
- **Aturan** (pada isi `class="..."`, `:class` string/array/object literal, dan argumen `cn(...)`):
  1. Palet mentah: `(bg|text|border|ring|outline|from|via|to|fill|stroke|divide|placeholder|shadow|decoration|accent|caret)-(slate|gray|zinc|neutral|stone|red|rose|orange|amber|yellow|lime|green|emerald|teal|cyan|sky|blue|indigo|violet|purple|fuchsia|pink)-\d{2,3}` dan `(bg|text|border)-(white|black)(/\d+)?` kecuali `text-white` di atas `bg-live`/`bg-primary` (boleh dilaporkan sebagai peringatan, bukan error).
  2. Hex/rgb di kelas arbitrer: `-\[(#|rgb|hsl|oklch)`.
  3. Ukuran teks arbitrer: `text-\[\d+(\.\d+)?(px|rem)\]`.
  4. `font-black`.
  5. `confirm(` / `prompt(` / `alert(` di `<script>`.
  6. Kelas `tactical-frame` / `tactical-frame-inner` atau `clip-path` di luar `Components/tactical/TacticalFrame.vue`.
- Output: `path:line  [aturan]  potongan`; exit code 1 bila ada error.

## Uji
- `npm run lint:ui -- resources/js/Pages/Dev/UiKit.vue` → 0 temuan.
- File uji sementara dengan `text-[10px] bg-slate-900 font-black` + `confirm('x')` → 4 temuan (hapus sebelum commit).
- `npm run lint:ui -- --all --report` → tulis total temuan per folder di Dev Notes (baseline migrasi).
