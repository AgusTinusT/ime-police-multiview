## DS-02a — Pasang komponen shadcn-vue
```bash
npx shadcn-vue@latest add button badge card input textarea label select native-select checkbox switch radio-group dialog alert-dialog sheet popover dropdown-menu tooltip tabs table avatar skeleton separator scroll-area sonner alert empty spinner progress pagination breadcrumb carousel aspect-ratio
```
- Hasil di `resources/js/Components/ui/<nama>/`. Jangan edit massal.
- Tambah varian proyek **sekali** di `Components/ui/badge/index.js` (cva): `success` (`bg-success/15 text-success border-success/30`), `warning`, `info`, `live` (`bg-live text-live-foreground`).
- Pasang `<Toaster rich-colors position="top-right" />` sekali di `resources/js/Layouts/TacticalLayout.vue` **dan** `AuthenticatedLayout.vue` (+ import CSS sonner bila diminta paketnya).

## DS-02b — Komponen taktis (`resources/js/Components/tactical/`)
Buat file + `index.js` yang mengekspor semuanya. Semua hanya memakai token & komponen `ui/`.

| File | Spesifikasi |
| :--- | :--- |
| `PageContainer.vue` | `div` `mx-auto w-full max-w-screen-2xl px-4 sm:px-6 lg:px-8` + slot |
| `PageHeader.vue` | props `eyebrow`, `title`, `description`; slot `actions`. Eyebrow: `font-mono text-xs uppercase tracking-wider text-primary` dibungkus `TacticalFrame variant="tag"`. Judul `font-heading text-3xl font-bold`. Layout: kolom di HP, baris (`sm:flex-row sm:items-end sm:justify-between`) di desktop |
| `SectionHeader.vue` | props `title`, `description`; slot `actions`; judul `font-heading text-2xl font-semibold` |
| `TacticalFrame.vue` | props `variant` (`panel`/`hero`/`tag`), `accent` (`primary`/`info`/`success`/`warning`/`live`/`dept-lspd`/…), `as` (default `div`). **Tanpa augmented-ui** — pakai utilitas CSS sendiri di `app.css` (lihat blok di bawah tabel). Struktur: `<component :is="as" class="tactical-frame" :data-variant="variant" :style="{ '--tf-color': `var(--color-${accent})` }"><div class="tactical-frame-inner"><slot /></div></component>` |

**CSS `TacticalFrame` (tambahkan di `resources/css/app.css`):**
```css
@utility tactical-frame {
  --tf-cut: 12px;
  --tf-border: 1px;
  --tf-shape: polygon(var(--tf-cut) 0, 100% 0, 100% calc(100% - var(--tf-cut)), calc(100% - var(--tf-cut)) 100%, 0 100%, 0 var(--tf-cut));
  position: relative;
  padding: var(--tf-border);
  background: var(--tf-color, var(--color-primary));
  @supports not (clip-path: polygon(0 0)) { border-radius: var(--radius-lg); }
  @supports (clip-path: polygon(0 0)) { clip-path: var(--tf-shape); }
  &[data-variant='hero'] { --tf-cut: 24px; }
  &[data-variant='tag'] { --tf-cut: 6px; --tf-border: 0px; background: color-mix(in oklab, var(--tf-color, var(--color-primary)) 15%, transparent); }
}
@utility tactical-frame-inner {
  height: 100%;
  background: var(--color-card);
  @supports (clip-path: polygon(0 0)) { clip-path: var(--tf-shape); }
  [data-variant='tag'] > & { background: transparent; }
}
```
(Sesuaikan bila sintaks `@supports` bersarang ditolak `@utility` — boleh dipindah ke blok CSS biasa di bawah `@layer components`. Uji di Chrome & Firefox.)
| `LiveBadge.vue` | `Badge variant="live"` + titik `motion-safe:animate-pulse` + teks `LIVE`; prop `viewers` → tampil "• 1.2K" (format `Intl.NumberFormat('id-ID', { notation: 'compact' })`) |
| `DeptBadge.vue` | prop `dept` → `Badge variant="outline"` dengan `border-dept-x/40 text-dept-x bg-dept-x/10`; nilai tak dikenal → netral |
| `StatTile.vue` | props `label`, `value`, `trend` (angka ±, warna success/destructive), `icon` (komponen lucide); berbasis `Card` |
| `OfficerAvatar.vue` | `Avatar` + `AvatarImage`/`AvatarFallback` (inisial); prop `live` → `ring-2 ring-live ring-offset-2 ring-offset-background`; `size`: sm/md/lg |
| `EmptyState.vue` | membungkus `Empty` (ikon, judul, deskripsi, slot `action`) |

Tambahkan di `app.css` utilitas opsional `.hud-grid` (latar grid `var(--hud-line)` 4% opacity, ukuran 24px) dan `.hud-corners` (4 sudut siku via `::before/::after` + background gradient) — README §4.

## DS-02c — Kompatibilitas `Components/Base/*`
Agar halaman lama tidak rusak, ubah isi `BaseButton`, `BaseBadge`, `BaseCard`, `BaseSectionHeader`, `BaseEmptyState`, `BaseSearchInput` menjadi **pembungkus tipis** di atas komponen baru (props lama dipetakan: `variant="primary"`→`default`, `secondary`→`secondary`, `danger`→`destructive`, `ghost`→`ghost`, `outline`→`outline`; `size` md→`default`). Beri komentar satu baris `// Deprecated: gunakan @/Components/ui/... (dihapus di MIG-10)`.

- `npm run build` sukses; halaman yang memakai `Base*` tetap tampil.
