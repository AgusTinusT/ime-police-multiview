# DS-00 — Upgrade Tailwind CSS v3.4 → v4

**Prioritas:** 🟠 P1 · **Estimasi:** sedang · **Commit:** `chore(ui): DS-00 upgrade tailwind to v4`
**Kenapa:** shadcn-vue versi aktif membutuhkan Tailwind v4. Upgrade dilakukan **sebelum** migrasi halaman agar tidak kerja dua kali.

## Prasyarat
- Working tree bersih (hanya `vite.config.js` lokal boleh berubah — jangan di-commit).
- Node 20+ (terpasang: Node 24).
- `@tailwindcss/vite@^4` sudah ada di `devDependencies`.

## Langkah
1. Ambil screenshot "sebelum" (390px & 1280px): `/`, `/multiview`, `/officers`, `/action-clips`, `/clipper`, `/admin/officers` (login admin), `/@<slug>` — simpan di luar repo.
2. Jalankan tool resmi:
   ```bash
   npx @tailwindcss/upgrade
   ```
   Tool akan: memindahkan konfigurasi ke CSS (`@theme`), mengganti `@tailwind ...` → `@import "tailwindcss";`, dan mengganti nama utility di template (`outline-none`→`outline-hidden` ±137×, `shadow-sm`→`shadow-xs` ±37×, `rounded-sm`→`rounded-xs`, dll.).
3. Pastikan build memakai plugin Vite v4:
   - `vite.config.js`: tambahkan `import tailwindcss from '@tailwindcss/vite'` dan `tailwindcss()` di `plugins` **(edit ini boleh di-commit; jangan ikutkan blok `server:` berisi IP LAN)** — pakai `git add -p` atau commit hanya hunk plugin.
   - Hapus `tailwindcss` dari `postcss.config.js` (atau hapus file bila kosong). `@tailwindcss/forms` → `@plugin "@tailwindcss/forms";` di `app.css`.
   - `package.json`: `tailwindcss` → `^4`.
4. **Pertahankan perilaku v3** yang berubah default:
   ```css
   @layer base {
     *, ::after, ::before, ::backdrop, ::file-selector-button { border-color: var(--color-gray-200, currentColor); }
   }
   ```
   (Akan diganti token `--border` di DS-01.) Cek `ring` tanpa angka → `ring-3` bila perlu.
5. Kelas lama `.tactical-card`, `.tactical-badge*`, `.btn-tactical-*` di `app.css` tetap berfungsi (`@apply` didukung). Blok `<style>` di `.vue` yang memakai `@apply` (bila ada) diberi `@reference "../../css/app.css";`.
6. `npm run build` → sukses. `php artisan test` → hijau.
7. Screenshot "sesudah" untuk halaman yang sama; bandingkan. Perbedaan kecil (shadow/ring) boleh; tata letak rusak tidak boleh.

## Catatan dukungan browser
Tailwind v4 butuh Safari 16.4+, Chrome 111+, Firefox 128+. **Disetujui product owner pada 29 Okt 2026** — tidak perlu fallback untuk browser lama.
