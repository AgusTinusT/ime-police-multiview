# UX-02 — Baris katalog "Momen aksi komunitas" (TacClips) di Dashboard

**Prioritas:** 🟡 P2 · **Estimasi:** kecil · **Bergantung:** —
**Commit:** `feat(ui): UX-02 baris momen aksi di dashboard`

## Konteks
Dashboard memakai baris katalog ala Netflix (`CatalogRow`). Komunitas belum terwakili di baris katalog. Data klip sudah tersedia di `GET /api/v1/tac-clips` (`id`, `video_id`, `title`, `start_seconds`, `end_seconds`, `officer_name`, `creator_name`, `likes_count`).

## File
- `resources/js/Pages/Dashboard.vue` (tambah baris + state)
- `resources/js/Components/ClipCatalogCard.vue` (baru)

## Yang harus dilakukan
1. Di `onMounted` Dashboard, ambil klip dengan `axios.get('/api/v1/tac-clips')`; simpan maksimal 12. Gagal → baris disembunyikan (tanpa toast).
2. Tambah `<CatalogRow title="Momen aksi komunitas">` **tepat setelah** baris "Sedang live" (sebelum baris TAC). Slot `#action`: `Button variant="link" size="sm"` + `Link href="/action-clips"` "Lihat semua".
3. `ClipCatalogCard.vue`: `Link href="/action-clips"`, lebar `w-52 sm:w-64`, thumbnail `https://i.ytimg.com/vi/{video_id}/mqdefault.jpg` (`aspect-video rounded-md object-cover`), `Badge variant="secondary"` durasi `m:ss` (end − start) di kanan bawah, judul `line-clamp-1 text-sm font-semibold`, baris kedua `text-xs text-muted-foreground`: `{officer_name} · oleh {creator_name} · {likes} suka` (ikon `Heart` dari `@lucide/vue` boleh). Ikuti gaya hover `CatalogCard.vue` (salin blok `<style scoped>`-nya).
4. Token & komponen UI kit saja (lihat playbook).

## Selesai jika
- [ ] Baris tampil saat ada klip, tersembunyi saat kosong/gagal.
- [ ] Klik kartu → `/action-clips`. Tidak ada scroll horizontal halaman di 390px.
- [ ] `npm run lint:ui` = 0 untuk kedua file; `npm run build` sukses.
