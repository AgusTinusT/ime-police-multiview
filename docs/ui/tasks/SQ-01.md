**Prioritas:** 🟠 P1 · **Estimasi:** menengah · **Bergantung:** —
**Commit:** `feat(squad): SQ-01 backend squad`

## Konsep
**Squad** = daftar officer buatan pengguna (mis. "SWAT563"). Squad menyimpan **officer**, bukan video: saat dibuka, yang tampil adalah siaran **live terbaru** tiap anggota. Visibilitas `private` (hanya pemilik) atau `public` (tampil di Dashboard). Pengguna lain bisa **fork** squad publik → salinan pribadi miliknya sendiri; squad asal **tidak berubah**. Wajib login untuk membuat/mengubah/fork. Admin bisa menyembunyikan squad publik.

## Skema
- `squads`: `id`, `user_id` (FK, cascade), `name` string(40), `slug` string unik, `description` string(160) nullable, `visibility` enum(`private`,`public`) default `private`, `forked_from_id` nullable (FK squads, null on delete), `forks_count` unsignedInteger default 0, `is_hidden` boolean default false, timestamps. Index `(visibility, is_hidden)`.
- `squad_officer`: `squad_id` (FK cascade), `officer_id` (FK cascade), `position` unsignedSmallInteger; unik `(squad_id, officer_id)`.

## API (JSON, `api/v1/squads`)
| Method & path | Middleware | Perilaku |
| :--- | :--- | :--- |
| `GET /public` | — | Squad `public` & tidak `is_hidden`, maks 24, berisi `name, slug, description, owner_name, forks_count, officers[] {id, officer_name, department, avatar_url, channel_id}, live_count`. Urut `live_count` desc, lalu `forks_count` desc. Cache 60 detik. |
| `GET /mine` | `auth` | Semua squad milik user (urut `updated_at` desc), bentuk sama. |
| `GET /{slug}` | — | Squad publik tidak tersembunyi, **atau** milik user login; selain itu 404. |
| `POST /` | `auth` | Buat: `name` (3–40), `description?`, `visibility`, `officer_ids[]` (1–`max_officers`, harus ada di tabel officers). Slug dari nama + akhiran acak. |
| `PUT /{squad}` | `auth` + pemilik | Ubah nama/deskripsi/visibilitas/`officer_ids` (urutan = posisi). Bukan pemilik → 403. |
| `DELETE /{squad}` | `auth` + pemilik | Hapus. |
| `POST /{squad}/fork` | `auth` | Hanya squad publik tidak tersembunyi (atau milik sendiri). Salinan `private` milik user dengan `forked_from_id`, nama `"{nama} (fork)"` dipotong ke 40; `forks_count` asal +1. Squad asal tidak diubah selain hitungannya. |
| `PATCH /api/v1/admin/squads/{squad}/hide` | `auth`,`admin` | Toggle `is_hidden`; panggil `AuditLogger::log('squad.hide', …)`. |

`live_count` = jumlah anggota yang punya `ActiveStream` berstatus `LIVE` (pakai relasi `Officer::activeStream`).

## Aturan
- `config/squads.php`: `max_per_user` = 20, `max_officers` = 12, `blocked_words` = [] (diisi admin nanti). Nama berisi kata terlarang (case-insensitive) → 422 dengan pesan Indonesia.
- Melebihi `max_per_user` → 422. Respons error mengikuti konvensi `GEMINI.md`.

## Test (wajib, jalur sukses & ditolak)
Buat squad; batas jumlah & anggota; nama terlarang; update/hapus oleh bukan pemilik → 403; `GET /{slug}` privat milik orang lain → 404; fork membuat salinan privat & menaikkan `forks_count` tanpa mengubah anggota squad asal; squad tersembunyi tidak muncul di `/public` & tidak bisa di-fork; hide oleh non-admin → 403.
