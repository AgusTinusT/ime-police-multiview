## Konteks
Section `TacticalSubSupportGrid` (Road to 1K) tetap dipertahankan. Tambahkan juga versi ringkas sebagai baris katalog, supaya ajakan subscribe terlihat lebih awal. Data: prop `supportOfficers` (`id`, `officer_name`, `department`, `avatar_url`, `subscriber_count`, `subscriber_count_text`, `is_live_now`, `youtube_url`).

## File
- `resources/js/Components/SupportCatalogCard.vue` (baru)
- `resources/js/Pages/Dashboard.vue` (tambah 1 baris katalog)

## Yang harus dilakukan
1. `SupportCatalogCard.vue`: kartu `w-44 sm:w-52`, `Card` berisi `OfficerAvatar` (size `lg`, prop `live` dari `is_live_now`), nama (`truncate text-sm font-semibold`), `DeptBadge`, `Progress` shadcn (nilai `min(100, subscriber_count / 10)`), teks `text-xs text-muted-foreground` "{n}/1.000 subscriber", dan `Button size="sm"` + `<a target="_blank" rel="noopener">` "Subscribe" ke `youtube_url`.
2. Dashboard: `<CatalogRow title="Road to 1K: dukung mereka">` ditaruh **sebelum** baris "Rekaman terbaru". Urutkan dari `subscriber_count` terbesar (paling dekat 1K dulu), maksimal 12. Sembunyikan baris jika `supportOfficers` kosong. Slot `#action`: link ke `#support-section` "Lihat semua".
3. Jangan mengubah `TacticalSubSupportGrid` atau section 4.
