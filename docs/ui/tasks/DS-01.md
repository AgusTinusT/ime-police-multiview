# DS-01 — Pasang shadcn-vue (mode JavaScript) + token tema gelap

**Prioritas:** 🟠 P1 · **Estimasi:** sedang · **Bergantung:** DS-00
**Commit:** `feat(ui): DS-01 shadcn-vue foundation and tactical tokens`
**Referensi:** `docs/design-system/README.md` §1–§2 (baca bagian ini saja).

## 1. Dependensi & konfigurasi
1. Jalankan init:
   ```bash
   npx shadcn-vue@latest init
   ```
   Jawab: style **new-york**, base color **slate**, CSS variables **ya**. Jika ditanya TypeScript → **tidak**.
2. Pastikan `components.json` akhirnya seperti ini (sesuaikan bila CLI menulis lain):
   ```json
   {
     "$schema": "https://shadcn-vue.com/schema.json",
     "style": "new-york",
     "typescript": false,
     "tailwind": { "config": "", "css": "resources/css/app.css", "baseColor": "slate", "cssVariables": true, "prefix": "" },
     "aliases": {
       "components": "@/Components",
       "ui": "@/Components/ui",
       "utils": "@/lib/utils",
       "lib": "@/lib",
       "composables": "@/Composables"
     },
     "iconLibrary": "lucide"
   }
   ```
   Alias `@/*` → `resources/js/*` sudah ada di `jsconfig.json` (jangan diubah).
3. Pastikan `resources/js/lib/utils.js` berisi `cn()` (clsx + tailwind-merge) dan dependensi terpasang: `clsx`, `tailwind-merge`, `class-variance-authority`, `reka-ui`, `lucide-vue-next`, `tw-animate-css` (atau yang diminta CLI).

## 2. Token (`resources/css/app.css`)
- Ganti blok `:root` / `.dark` hasil CLI dengan nilai README §2.1 (isi **sama** di `:root` dan `.dark`, karena dark-only).
- Tambahkan token proyek README §2.2 (`--success`, `--warning`, `--info`, `--live`, `--dept-*`, `--hud-line` + pasangan `-foreground`) dan daftarkan di `@theme inline` (`--color-success: var(--success);` dst.).
- Ganti aturan border kompatibilitas dari DS-00 menjadi `border-color: var(--color-border)` (pola standar shadcn: `* { @apply border-border outline-ring/50; }`, `body { @apply bg-background text-foreground; }`).
- Font di `@theme`: `--font-sans: "Plus Jakarta Sans", Inter, ui-sans-serif, system-ui, sans-serif;`, `--font-mono: "JetBrains Mono", ui-monospace, monospace;`, `--font-heading: "Rajdhani", sans-serif;`.
- Kelas lama `.tactical-*`/`.btn-tactical-*` **tetap** (dihapus di MIG-10).

## 3. Dark-only
- `resources/views/app.blade.php`: `<html ... class="dark">` dan `<meta name="color-scheme" content="dark">`.
- `resources/css/app.css`: **wajib** `@custom-variant dark (&:is(.dark *));` (di bawah `@import`), agar varian `dark:` di komponen shadcn mengikuti kelas `.dark`, bukan pengaturan tema OS pengguna.

## 4. ~~augmented-ui~~ — DIBATALKAN (Review DS-01)
augmented-ui menambah 167 KB (17 KB gzip) CSS render-blocking di semua halaman untuk 3 bentuk saja. Aksen taktis dibuat sendiri dengan `clip-path` di `TacticalFrame` (DS-02b). **Jangan** pasang/import augmented-ui.

## Uji
- `npx shadcn-vue@latest add button` berhasil membuat `resources/js/Components/ui/button/*.vue` berformat **JavaScript** (tanpa `lang="ts"`). (Komponen lain dipasang di DS-02 — boleh langsung lanjut.)
- `npm run build` sukses; `php artisan test` hijau; halaman lama tidak berubah drastis (warna latar/teks tetap gelap).
