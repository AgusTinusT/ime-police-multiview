# UX-01 — i18n untuk katalog Dashboard, modal detail, dan bar tile Multiview

**Prioritas:** 🟡 P2 · **Estimasi:** kecil · **Bergantung:** —
**Commit:** `feat(ui): UX-01 i18n katalog dashboard & tile multiview`

## Konteks
Teks berikut masih ditulis langsung (hardcode) dalam bahasa Indonesia, jadi pengalih bahasa EN/ID tidak menerjemahkannya.

## File
- `resources/js/Pages/Dashboard.vue` — hanya blok `SECTION 2: Catalog rows` dan tray (`POV dipilih`, `Kosongkan`, `Buka multiview`, `Tonton semua`, `Sedang live`, `Insiden aktif`, `Top 10 patroli bulan ini`, `Patroli {dept}`, `Rekaman terbaru`, `Satu kejadian, setiap sudut`, `{n} unit · {n} menonton`).
- `resources/js/Components/CatalogCard.vue` — `menonton`, `aria-label` tombol.
- `resources/js/Components/CatalogRow.vue` — `aria-label` panah.
- `resources/js/Components/OfficerDetailModal.vue` — semua teks.
- `resources/js/Pages/Multiview.vue` — hanya bar tile: `REKAMAN`, `OFFLINE`, `aria-label` tombol (`Bisukan`, `Dengarkan POV ini`, `Jadikan utama`, `Tutup POV`, `Tonton … sebagai utama`).
- `resources/js/locales/id.json` dan `resources/js/locales/en.json`.

## Yang harus dilakukan
1. Tambah grup kunci baru `catalog` (Dashboard + kartu + baris), `officer_detail` (modal), dan `multiview_tile` (bar tile) di kedua file locale. Teks `id` = teks sekarang, persis.
2. Ganti teks di file Vue dengan `$t()` / `t()` (`useI18n`). Pakai parameter untuk angka (`{count}`), jangan menyambung string.
3. Jangan mengubah markup, kelas, atau logika lain.

## Selesai jika
- [ ] Tidak ada teks UI hardcode yang tersisa di bagian yang disebut di atas.
- [ ] Ganti bahasa ke EN → semua teks di atas berubah; ID → sama persis seperti sebelumnya.
- [ ] `npm run lint:ui -- <file>` = 0 untuk tiap file Vue yang diubah; `npm run build` sukses.
