# T-04 — Logout perangkat lain saat ganti password (belum efektif)

**Prioritas:** 🟠 P1 · **Estimasi:** kecil · **Commit:** `fix(biolink): T-04 enforce other-device logout via AuthenticateSession`

## Masalah
`PasswordController::update()` memanggil `Auth::logoutOtherDevices()`, tetapi fungsi itu hanya memutus sesi lain bila middleware `\Illuminate\Session\Middleware\AuthenticateSession` aktif di grup `web`. Di `bootstrap/app.php` middleware itu belum ada → sesi lain tetap login.

## File
- `bootstrap/app.php` → `$middleware->web(append: [...])`
- `app/Http/Controllers/Auth/PasswordController.php` (cek saja)

## Yang harus dilakukan
1. Tambahkan `\Illuminate\Session\Middleware\AuthenticateSession::class` ke `web(append: [...])` **sebelum** `EnsureNotBanned`.
2. Pastikan `PasswordController` tetap memanggil `Auth::logoutOtherDevices($validated['password'])` setelah password diperbarui (sesi saat ini tetap login).

## Test (wajib) — `tests/Feature/BioLink/AccountSecurityTest.php`
- User login (sesi A) → simpan `password_hash_web` lama di sesi lain (sesi B: `withSession(['password_hash_web' => $oldHash])` + `actingAs`) → ganti password dari sesi A via `PUT /password` → request berikutnya dari sesi B (masih membawa hash lama) diarahkan ke login / tidak terautentikasi.
- Sesi A yang mengganti password tetap terautentikasi.

> Jika pola test di atas sulit di Laravel 13, alternatif implementasi yang diterima: hapus baris tabel `sessions` milik user kecuali `session()->getId()` saat ini, dan test dengan `SESSION_DRIVER=database` di test. Tulis pilihan di Dev Notes.
