## Alur (contoh e'ido)
Admin sudah mendaftarkan officer e'ido (`channel_id` diketahui) → e'ido login (email terverifikasi) → pilih profil unclaimed → dapat token → tempel di deskripsi channel YouTube → klik "Periksa Sekarang" → sistem menemukan token di channel **milik `officers.channel_id`** → bind otomatis.

## T-14a — Backend
**1. `OfficerBindingService::bind(Officer $officer, User $user, string $reason, ?int $actorId)`** — satu-satunya tempat logika bind (dipakai `OfficerBindingController::bindUser`, approve manual, dan auto-approve):
transaksi + `lockForUpdate` officer → tolak bila user banned / email belum verifikasi / user sudah terikat officer lain / officer terikat user lain → set `user_id` → `BioProfileService::ensureBioProfile` + `is_active = true` → `invalidatePublicCache` → `AuditLogger::log('officer.bind', ...)`. Refactor pemanggil lama agar memakai service ini (perilaku & pesan tetap sama, test lama tetap hijau).

**2. Token**
- Format `SASP-VERIFY-XXXX-XXXX-XXXX-XXXX`, alfabet `ABCDEFGHJKLMNPQRSTUVWXYZ23456789` (tanpa 0/O/1/I), pakai `random_int` → 80 bit.
- Simpan **hanya** `hash('sha256', $token)` di `verification_token_hash`; `token_expires_at = now()->addDay()`.

**3. `YouTubeChannelVerifier::findTokenHashes(string $channelId): array`**
- Ambil halaman: `https://www.youtube.com/channel/{channelId}/about` dan `https://www.youtube.com/channel/{channelId}/live` via `Http::timeout(10)->withHeaders(['Accept-Language' => 'id-ID,en;q=0.8'])`. Jika `config('services.youtube.key')` ada, boleh pakai API `channels.list?part=snippet&id=` sebagai sumber utama.
- Cari semua kemunculan regex `/SASP-VERIFY(?:-[A-Z0-9]{4}){4}/i` di body, uppercase, kembalikan daftar `sha256`-nya.
- Kegagalan HTTP → kembalikan `[]` dan `Log::warning` (jangan lempar exception ke user).

**4. Endpoint** (grup `auth`, `verified`, `not_banned`, prefix `api/v1/officer-claims`):
- `POST /youtube` `{officer_id}` — `throttle:3,1440`. Tolak bila user sudah terikat, officer sudah terikat/nonaktif, atau ada klaim pending (user/officer). Buat klaim `verification_method=youtube_token`. Respons 201 berisi **token mentah (sekali saja)**, `expires_at`, `channel_url` (dari `channel_id`).
- `POST /{claim}/verify-youtube` — `throttle:5,60`. Hanya pemilik klaim (403), status harus `pending` + metode `youtube_token`. Kedaluwarsa → set `expired`, 422. `check_attempts++`, `last_checked_at=now()`. Jika hash klaim ada di hasil verifier → `OfficerBindingService::bind(..., 'Verifikasi otomatis YouTube', null)`, klaim `approved` (`reviewed_by` NULL, `reviewed_at` now, `review_reason` "Verifikasi otomatis YouTube"), audit `claim.auto_approved`. Jika tidak → 422 "Kode belum ditemukan di deskripsi channel. Pastikan sudah disimpan, lalu coba lagi dalam beberapa menit."
