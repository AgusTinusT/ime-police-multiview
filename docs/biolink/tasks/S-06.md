## File
`tests/Feature/BioLink/PlatformLinkTest.php` (baru). Pakai factory/helper yang sudah dipakai test bio-link lain.

## Kasus
1. **Urutan publik = urutan dashboard.** Buat 3 link: Saweria (sort 2), Instagram (sort 0), Discord (sort 1).
   `GET /@{slug}` → prop `links` berurutan Instagram, Discord, Saweria. Lalu `POST /api/v1/officer/bio-links/reorder`
   dengan urutan baru → halaman publik ikut berubah (bersihkan cache halaman bila perlu).
2. **Platform menentukan nama & tipe.** POST `{ platform: 'instagram', url: 'https://instagram.com/x' }` tanpa `title`
   → tersimpan `title = 'Instagram'`, `link_type = 'social'`.
3. **Domain harus cocok platform.** `{ platform: 'instagram', url: 'https://tiktok.com/@x' }` → 422 pada `url`.
4. **Platform tidak dikenal** → 422 pada `platform`.
5. **Custom wajib nama.** `{ platform: 'custom', url: 'https://example.com' }` tanpa `title` → 422; dengan `title` → 201.
6. **Donasi tetap minta konfirmasi password** (`platform: 'saweria'` tanpa konfirmasi → ditolak, sama seperti test T-03 yang sudah ada).
7. **Backfill.** Link lama tanpa `platform` dengan `url_host = 'saweria.co'` → setelah migrasi/command backfill `platform = 'saweria'`;
   host tak dikenal → `custom`. (Ikuti cara backfill yang dipilih di S-01 — lihat Dev Notes S-01.)
8. **Prop publik `links` membawa `platform`** dan tetap satu array berurutan (rekan patroli ikut di dalamnya dengan `link_type = officer_recommendation`; `BioLinkView.vue` memisahkannya ke kartu "Rekan patroli"). Pastikan link URL bersebelahan sesuai `sort_order` dan field `platform` terisi.
