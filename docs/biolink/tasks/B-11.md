# B-11 — Regresi telemetri klik `/go/{link}`

**Prioritas:** 🟠 P1 · **Estimasi:** kecil · **Commit:** `fix(biolink): B-11 restore privacy-preserving click telemetry`

## Masalah
`PublicBioLinkController::handleClick()` menulis kolom `officer_bio_profile_id`, `ip_hash`, `user_agent`, `referrer` yang **tidak ada** di tabel `bio_link_clicks` (kolom asli: `officer_bio_link_id`, `visitor_hash`, `referer_host`, `created_at`). Eloquent membuangnya diam-diam → `visitor_hash` & `referer_host` selalu NULL. Selain itu hash statis `sha256(ip + APP_KEY)` dan penyimpanan User-Agent melanggar aturan privasi (PRD 7G: HMAC dengan salt harian, tanpa UA).

## File
- `app/Http/Controllers/PublicBioLinkController.php` → `handleClick()`

## Yang harus dilakukan
Ganti blok perekaman klik dengan versi ini (sama seperti baseline commit `a8f4e45`):
```php
$ip = $request->ip() ?: '0.0.0.0';
$ua = $request->userAgent() ?: 'unknown';
$dailySalt = date('Ymd') . config('app.key');
$visitorHash = hash_hmac('sha256', "{$ip}|{$ua}", $dailySalt);

$referer = $request->headers->get('referer');
$refererHost = $referer ? parse_url($referer, PHP_URL_HOST) : null;

BioLinkClick::create([
    'officer_bio_link_id' => $link->id,
    'visitor_hash' => $visitorHash,
    'referer_host' => $refererHost ? substr($refererHost, 0, 190) : null,
]);
```
Biarkan logika `BioDailyStat` (increment clicks), guard keamanan, dan redirect apa adanya.

## Test (wajib) — `tests/Feature/BioLink/ClickTelemetryTest.php`
- `GET /go/{link}` dengan header `Referer: https://discord.com/channels/1` → redirect 302 ke URL link; baris `bio_link_clicks` punya `visitor_hash` 64 karakter (bukan NULL) dan `referer_host = 'discord.com'`.
- Dua klik dari IP+UA sama di hari yang sama → `visitor_hash` sama.
- Tanpa Referer → `referer_host` NULL, klik tetap tercatat.
