# T-20 — Uji end-to-end alur "e'ido" + test gabungan v3

**Prioritas:** 🟡 P2 · **Estimasi:** kecil · **Bergantung:** T-14 s.d. T-19 · **Commit:** `test(biolink): T-20 end-to-end ownership flow`

## Test otomatis — `tests/Feature/BioLink/OwnershipFlowTest.php`
Satu test berurutan (pakai `Http::fake` untuk YouTube):
1. Admin membuat officer "e'ido" via `POST /api/v1/officers` (unclaimed).
2. User baru mendaftar + email diverifikasi (`markEmailAsVerified()`).
3. `POST /api/v1/officer-claims/youtube` → ambil token dari respons.
4. Fake halaman `/channel/{channel_id}/about` berisi token → `POST /{claim}/verify-youtube` → 200, officer terikat.
5. `PUT /api/v1/officer/profile` ubah callsign → `GET /@{slug}` (props Inertia) menampilkan callsign baru.
6. `POST /api/v1/officer/change-requests` rank → admin approve → rank berubah.
7. Pemilik menambah link Discord di `/api/v1/officer/bio-links` → tampil di `/@{slug}`.
8. Admin unbind → `/@{slug}` 404; pengajuan pending (jika ada) `cancelled`; data dinas terakhir tetap.

## Uji manual (di browser, lingkungan lokal)
Ulangi alur di atas lewat UI (admin panel, modal klaim, halaman Profil Dinas, halaman publik). Untuk langkah YouTube, gunakan channel uji milik tim atau sementara `Http::fake` tidak berlaku — catat channel yang dipakai. Tulis ringkasan hasil per langkah (OK/gagal) di Dev Notes.
