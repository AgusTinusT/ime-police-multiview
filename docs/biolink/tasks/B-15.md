# B-15 — Jumlah penonton & durasi dinas tidak tampil di halaman bio-link

**Prioritas:** 🟡 P2 · **Estimasi:** sangat kecil · **Commit:** `fix(biolink): B-15 use viewers_count column`

## Masalah
`PublicBioLinkController` (method `show` ≈ baris 156 dan `liveStatus` ≈ baris 256) membaca `$activeStream->viewer_count` dan `$activeStream->duty_minutes`. Kolom asli di tabel `active_streams` adalah **`viewers_count`**, dan `duty_minutes` **tidak ada**. Akibatnya badge "👁️ … penonton" di `Pages/Public/BioLink.vue` tidak pernah muncul.

## Yang harus dilakukan
1. Ganti sumber nilai menjadi `$activeStream->viewers_count` (nama key prop `viewer_count` di frontend boleh tetap, agar `BioLink.vue` tidak perlu diubah).
2. Hapus `duty_minutes` dari kedua payload (atau isi dari `officers.monthly_duty_minutes` bila memang ingin ditampilkan — pilih hapus bila tidak dipakai di `BioLink.vue`; cek dengan `grep duty_minutes resources/js`).
3. Kebersihan (dari Review #4): di `recordPageView()` hapus blok yang menulis `bio_views_pending:{date}` — `FlushBioViews` kini mengiterasi profil langsung sehingga daftar itu tidak dipakai lagi. Pertahankan `Cache::add` + `Cache::increment`. Test view counter yang ada harus tetap lulus.

## Test
