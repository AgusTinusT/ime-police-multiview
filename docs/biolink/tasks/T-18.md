# T-18 — UI Profil Dinas Mandiri + antrean pengajuan admin

**Prioritas:** 🟠 P1 · **Estimasi:** sedang (frontend) · **Bergantung:** T-16, T-17
**Commit dipecah dua:** `feat(biolink): T-18a officer self-profile page` lalu `feat(biolink): T-18b admin change request tab`.

## T-18a — Halaman pemilik `/dashboard/officer-profile`
**Backend kecil:** route web `GET /dashboard/officer-profile` (grup `auth`, `verified`, `officer`, `not_banned`) → `Inertia::render('Officer/OfficerProfile', [...])` dengan data awal dari logika `GET /api/v1/officer/profile` (boleh dipanggil ulang dari Vue via axios). User tanpa officer (mis. admin) → redirect ke `/dashboard/bio-links` dengan pesan.

**Halaman `resources/js/Pages/Officer/OfficerProfile.vue`** — ikuti gaya visual `BioLinksDashboard.vue` (tema gelap taktis, layout responsif 360px):
1. **Kartu "Identitas"** (edit langsung): nama karakter, nama streamer, avatar URL (+ pratinjau), patrol zone, divisi (dropdown dari agency officer).
2. **Kartu "Penanda Unit"** (edit + cek): callsign, badge; tampilkan "Bisa diubah lagi pada {tanggal}" bila terkena batas 7 hari (input nonaktif).
3. **Kartu "Pangkat & Kesatuan"** (lewat persetujuan): nilai saat ini + tombol "Ajukan Perubahan" → modal (pilih agency/rank, alasan) → `POST /api/v1/officer/change-requests`. Daftar pengajuan dengan status (Menunggu / Disetujui / Ditolak + alasan) dan tombol batalkan untuk pending.
4. **Kartu "Identitas YouTube"** (terkunci 🔒): channel ID, handle, slug bio-link — read-only + teks "Hubungi admin untuk mengubah".
5. **Riwayat perubahan** dari `/api/v1/officer/profile/history`.
- Simpan → `PUT /api/v1/officer/profile` hanya dengan field yang berubah. Error 422 ditampilkan di bawah field terkait (`err.response.data.errors`), 423 sebagai banner "Profil sedang dibekukan".
- **Entry point:** item menu "Profil Dinas Saya" di `resources/js/Components/UserAccountMenu.vue` (di dekat link `/dashboard/bio-links`) untuk user yang punya `officer_profile`.

## T-18b — Tab admin "Pengajuan Perubahan"
- `resources/js/Pages/Admin/OfficerManagement.vue`: tambah tab baru setelah tab `claims` (pola tombol `@click="activeTab = '...'"` yang sama), dengan badge jumlah pending (tambahkan `pending_change_requests` ke `stats` di `OfficerManagementController::adminPage`).
- Komponen baru `resources/js/Components/Admin/OfficerChangeRequestsTab.vue` (contoh pola: `OfficerClaimsTab.vue`): filter status, tabel (officer, field, lama → baru, alasan pemilik, tanggal), tombol Setujui (confirm) / Tolak (prompt alasan wajib), emit `toast` dan `updated`.
