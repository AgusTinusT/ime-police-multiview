# T-17 — Pengajuan & persetujuan Rank / Agency

**Prioritas:** 🟠 P1 · **Estimasi:** sedang · **Bergantung:** T-15 · **Commit:** `feat(biolink): T-17 rank and agency change requests`
**WIP:** `app/Http/Controllers/OfficerChangeRequestController.php` sudah ada — lanjutkan.

## Endpoint pemilik (grup `auth`, `verified`, `officer`, `not_banned`)
- `GET /api/v1/officer/change-requests` → pengajuan milik officer user (terbaru dulu).
- `POST /api/v1/officer/change-requests` `{field: 'rank_id'|'agency_id', new_value: int, reason?: string max 255}` → `throttle:10,60`.
  - Officer = milik user (bukan dari request). Profil suspended → 423.
  - `agency_id`: harus ada di `agencies`, ≠ nilai saat ini.
  - `rank_id`: harus ada di `ranks`, ≠ nilai saat ini, dan `rank.agency_id` = agency officer saat ini **atau** = agency pada pengajuan `agency_id` yang sedang pending.
  - Sudah ada pending untuk field sama → 422 (dijamin juga oleh unique index T-15).
  - Simpan `old_value` = nilai saat ini. Audit `officer.change_requested`.
- `DELETE /api/v1/officer/change-requests/{request}` → hanya milik sendiri & masih `pending` → `cancelled`.

## Endpoint admin (grup `auth`, `admin`, prefix `api/v1/admin`)
- `GET /officer-change-requests?status=pending|all` (paginate 20, with officer + requester + nama rank/agency lama & baru agar UI tidak perlu query lagi).
- `POST /officer-change-requests/{request}/approve` `{reason?}`:
  - Transaksi + `lockForUpdate` officer. Status harus `pending`.
  - Jika nilai officer saat ini ≠ `old_value` → set `rejected` dengan `review_reason` "Pengajuan usang: data sudah berubah", 422.
  - Terapkan: `agency_id` → set `agency_id` + `department = agency.agency_code`; jika rank saat ini bukan milik agency baru → `rank_id = null` (beri tahu di pesan). `rank_id` → set `rank_id` + `rank = rank.rank_title`.
  - Status `approved`, `reviewed_by`, `reviewed_at`. Audit `officer.change_approved`. Invalidasi cache bio publik.
- `POST /officer-change-requests/{request}/reject` `{reason: required min 5}` → `rejected`, audit `officer.change_rejected`.

## Integrasi
- `OfficerBindingController::unbindUser` (atau `OfficerBindingService` bila unbind sudah dipindah): set semua pengajuan `pending` officer tersebut → `cancelled`.
