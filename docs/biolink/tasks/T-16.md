## Endpoint (grup `auth`, `verified`, `officer`, `not_banned`)
- `GET /api/v1/officer/profile` → data officer milik user + daftar divisi untuk agency-nya + info batas (`callsign_next_change_at`, `name_changes_left`).
- `PUT /api/v1/officer/profile` → `throttle:10,1`.
- `GET /api/v1/officer/profile/history` → audit log dengan `subject_type='officer'` & `subject_id` officer ini (30 terbaru).

## Aturan `PUT`
1. Officer = `$request->user()->officer`; tidak ada → 403. **Tidak menerima `officer_id`.** Admin tidak memakai endpoint ini.
2. Ambil hanya field whitelist: `$data = $request->only([...7 field...])`. Field terkunci yang dikirim → **422** dengan pesan "Field X tidak dapat diubah sendiri" (lebih jelas daripada diabaikan diam-diam).
3. Profil bio suspended → 423.
4. Validasi:
   - `officer_name`, `streamer_name`: string 2–150; cek `NameSkeleton::checkName($nama, $user->id)` → bila `blocked` → 422. (Nama yang sama dengan dirinya sendiri harus lolos — `checkName` sudah melewati officer milik `ignoreUserId`.)
   - `callsign`: uppercase + trim, regex `^[A-Z0-9][A-Z0-9-]{1,49}$`.
   - `badge_number`: regex `^#?[0-9A-Z-]{1,20}$`.
   - `patrol_zone`: string max 150, nullable.
   - `division_id`: nullable, `exists:divisions,id` **dan** `division.agency_id == officer.agency_id`.
   - `avatar_url`: nullable, `https://`, host ∈ `config('biolinks.avatar_hosts')` (tambahkan: `yt3.ggpht.com`, `yt3.googleusercontent.com`, `i.ytimg.com`).
5. Dalam transaksi dengan `lockForUpdate` pada officer:
   - Callsign berubah → cek tidak ada officer aktif lain dengan `callsign_normalized` sama (422 bila ada); cek `callsign_changed_at` < now−7 hari (422 + tanggal kapan boleh lagi); set `callsign_changed_at=now()`.
   - Badge berubah → cek unik di antara officer aktif (422).
   - Nama berubah → hitung `AuditLog` action `officer.name_changed` untuk officer ini 30 hari terakhir; ≥3 → 422.
   - Avatar berubah → `avatar_is_custom = true`.
   - Set `owner_updated_at = now()`.
6. Audit: `officer.self_updated` (before/after hanya field yang berubah); tambahan `officer.name_changed` bila nama berubah; `officer.callsign_changed` bila callsign/badge berubah (memicu alert Discord lewat AuditLogger).
7. `BioProfileService::invalidatePublicCache($officer->bioProfile->slug)` bila ada profil.
