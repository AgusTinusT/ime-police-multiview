# B-05 — Keyword terlarang memblokir nama umum (false positive)

**Prioritas:** 🟠 P1 · **Estimasi:** kecil · **Commit:** `fix(biolink): B-05 token-based reserved keyword matching`

## Masalah
`NameSkeleton::checkName()` sekarang memakai `str_contains($skeleton, $keywordSkeleton)` pada skeleton **seluruh nama tanpa spasi**. Akibatnya nama asli diblokir saat registrasi:
- `Saprudin`, `Siti Sapriyah` → mengandung `sapr`
- `Ahmad Mintoro` → `ahmadmintoro` mengandung `admin`
- `Badminton Lover` → mengandung `admin`

## File
- `app/Services/NameSkeleton.php` → bagian "Check against reserved keywords" di `checkName()`

## Yang harus dilakukan
Cocokkan keyword **per token kata**, bukan substring:
```php
// pecah camelCase lalu pisah di spasi / tanda baca
$spaced = preg_replace('/(?<=\p{Ll})(?=\p{Lu})/u', ' ', $name);
$tokens = preg_split('/[\s._\-|]+/u', $spaced, -1, PREG_SPLIT_NO_EMPTY);
$tokenSkeletons = array_map(fn ($t) => self::make($t), $tokens);

foreach ($reserved as $keyword) {
    $kw = self::make($keyword);
    if ($kw !== '' && ($skeleton === $kw || in_array($kw, $tokenSkeletons, true))) {
        return ['blocked' => true, 'reason' => '...pesan yang sama...', 'flagged' => false];
    }
}
```
Pengecekan terhadap nama officer (exact skeleton + Levenshtein) **tidak diubah**.
