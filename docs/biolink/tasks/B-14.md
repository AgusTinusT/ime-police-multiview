# B-14 — Bind menulis `users.role = 'officer'`

**Prioritas:** 🔴 P0 · **Estimasi:** sangat kecil · **Commit:** `fix(biolink): B-14 stop writing officer role on bind`

## Masalah
`app/Services/OfficerBindingService.php` → `bind()` berisi:
```php
// Upgrade user role to 'officer' if not admin
if ($user->role !== 'admin') {
    $user->role = 'officer';
    $user->save();
}
```
Status officer harus diturunkan dari relasi (`$user->officer`), bukan dari `users.role`. Dampak: user `clipper` yang di-bind menjadi `officer`; saat unbind, transisi legacy (`officer` → `member`) membuat **status clipper hilang**.

## Yang harus dilakukan
1. Hapus blok di atas seluruhnya. Jangan menulis `users.role` di mana pun dalam alur bind/klaim.
2. Cari penulisan serupa: `grep -rn "role = 'officer'\|'role' => 'officer'" app` — hapus bila ada di alur bio-link (biarkan command admin seperti `MakeAdminCommand`).

## Test (wajib) — tambahkan ke test binding
- User `role=clipper`, `clipper_tier=creator`, email terverifikasi → admin bind → `role` tetap `clipper`, `isOfficer()` true.
- Unbind → `role` tetap `clipper`, `clipper_tier` tetap, `isOfficer()` false.
- Klaim YouTube auto-approve → `role` user tidak berubah.

- [ ] Tidak ada penulisan `role = 'officer'` di alur bind/klaim.
