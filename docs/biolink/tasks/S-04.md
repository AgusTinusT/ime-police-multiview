# S-04 — `PlatformIcon.vue`: ikon merek per platform

**Prioritas:** 🟠 P1 · **Estimasi:** kecil · **Commit:** `feat(biolink): S-04 platform icon component`
Konteks: [SIMPLE-LINKS.md](../SIMPLE-LINKS.md) (baca bagian "Daftar platform awal").

## Yang dibuat
`resources/js/Components/BioLink/PlatformIcon.vue` + `resources/js/Components/BioLink/platformIcons.js`.

```vue
<PlatformIcon platform="instagram" class="size-5" />
```

- Props: `platform` (string, wajib). Key tidak dikenal atau `custom` → ikon `Link2` dari `@lucide/vue`.
- `platformIcons.js` mengekspor objek `{ key: { path, viewBox } }` berisi path SVG satu warna.
  - Instagram, TikTok, YouTube, Discord, Twitch, X, Facebook: ambil path dari **Simple Icons** (lisensi CC0)
    — salin path-nya saja ke file JS, **jangan** menambah dependency npm.
  - Saweria, Bagibagi, Trakteer, Tako, Sociabuzz: bila tidak ada di Simple Icons, buat monogram
    sederhana (huruf awal tebal di dalam bentuk bulat/kotak membulat) sebagai path SVG `viewBox="0 0 24 24"`.
- Warna **selalu `currentColor`** (`fill="currentColor"`). Komponen tidak memberi warna merek; warna
  diatur oleh pemanggil lewat tema. Jangan pakai `#hex` di path.
- `aria-hidden="true"`; nama platform ditulis pemanggil sebagai teks.
