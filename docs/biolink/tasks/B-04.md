# B-04 — Hentikan tipe `officer` di Clipper Request (keputusan D4a)

**Prioritas:** 🟠 P1 · **Estimasi:** kecil · **Commit:** `fix(biolink): B-04 retire officer clipper request type`

## Konteks
Bagian role sudah benar (approve tidak menimpa role officer). Yang belum: tipe pengajuan `officer` masih bisa dikirim. Sesuai D4(a), officer cukup **mengklaim profil**; officer yang terikat otomatis mendapat tier clipper officer.

## File
- `app/Http/Controllers/ClipperRequestController.php` → validasi `request_type` (sekitar baris 58: `in:officer,creator,vip,general`)
- `resources/js/Pages/ClipperPricing.vue` → tombol yang memanggil `openClaimModal('officer')` (sekitar baris 634)
- `resources/js/Components/UserAccountMenu.vue` → sudah punya entry point `OfficerClaimModal` (pakai ulang)

## Yang harus dilakukan
1. Backend: ubah validasi menjadi `in:creator,vip,general`. Data lama berjenis `officer` **tidak diubah/dihapus**; tampilan admin untuk data lama tetap jalan.
2. `ClipperPricing.vue`: tombol paket Officer tidak lagi membuka form clipper request. Ganti menjadi:
   - user belum login → buka modal login/daftar seperti tombol lain;
   - user login & belum terikat officer → buka `OfficerClaimModal` (klaim profil officer);
   - user sudah terikat officer → tampilkan teks "Akses Officer aktif".
3. Teks penjelasan singkat: "Perwira: klaim profil Anda untuk akses clipper officer."

## Test (wajib) — tambahkan ke `tests/Feature/BioLink/ClipperOfficerTest.php`
- `POST /api/v1/clipper-requests` dengan `request_type=officer` → 422.
- `request_type=creator` tetap 201/berhasil.
- User terikat officer → approve clipper request `creator` → `isOfficer()` tetap true.
