**Prioritas:** 🟡 P2 · **Estimasi:** sangat kecil · **Commit:** `fix(biolink): B-13 use correct agency and rank columns`

## Masalah
`PublicBioLinkController::show()` membaca kolom yang tidak ada:
- `$officer->rankRelation?->name` → kolom asli **`rank_title`**
- `$officer->agency?->name` → kolom asli **`agency_name`**
- `$officer->agency?->badge_image_url` → kolom asli **`badge_logo_url`**

Akibatnya pangkat/agency selalu jatuh ke teks lama dan logo agency tidak pernah tampil (melanggar D3: relasi dulu, teks sebagai fallback).

## File

- Cek juga `grep -rn "rankRelation?->name\|agency?->name\|badge_image_url" app resources/js` dan perbaiki yang sejenis.
