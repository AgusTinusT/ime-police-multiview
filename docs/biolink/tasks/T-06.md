# T-06 — UI Suspend Bio-Link & Ban/Unban User (belum ada)

**Prioritas:** 🟠 P1 · **Estimasi:** sedang (frontend saja) · **Commit:** `feat(biolink): T-06 admin suspend bio and ban user controls`

## Masalah
API sudah ada, tapi tidak ada tombol di UI admin:
- `PATCH /api/v1/admin/bio-profiles/{profile}/suspend` body `{ is_suspended: bool, reason: string(min 3) }`
- `PATCH /api/v1/admin/users/{user}/status` body `{ status: 'active'|'banned', reason: string (wajib bila banned) }`

## File
- `resources/js/Pages/Admin/OfficerManagement.vue`
  - Tab **officers**: baris officer sudah menampilkan label `SUSPENDED` (`officer.bio_profile?.is_suspended`, sekitar baris 1964) dan tombol aksi binding.
  - Tab **users** (`activeTab === 'users'`, sekitar baris 2396): daftar user dari `GET /api/v1/admin/users` (sudah memuat kolom `status`).
- Backend **tidak perlu diubah**.

## Yang harus dilakukan
1. **Tab officers**, di samping aksi binding, untuk officer yang punya `bio_profile`:
   - Tombol `🔴 Suspend Bio` (jika belum suspended) / `🟢 Cabut Suspend` (jika suspended).
   - Klik → `prompt('Alasan ...')` (wajib, min 3 karakter; batal = tidak jadi) → PATCH suspend → toast → refresh daftar officer (`fetchOfficers`).
2. **Tab users**, per baris:
   - Badge `BANNED` merah bila `status === 'banned'` (+ tooltip `banned_reason`).
   - Tombol `Ban` (prompt alasan wajib) / `Unban` (confirm) → PATCH status → toast → refresh daftar user.
   - Sembunyikan tombol Ban untuk akun yang sedang login (jangan ban diri sendiri).
3. Error 422 tampilkan `err.response.data.message` atau pesan validasi pertama.

## Uji
- `npm run build` sukses.
- Uji manual di browser: suspend → buka `/@{slug}` tampil kartu "DINONAKTIFKAN"; cabut suspend → normal; ban user → user tersebut ter-logout pada request berikutnya. Tulis hasil singkat di Dev Notes.

- [ ] Ban/unban bisa dilakukan dari UI; admin tidak bisa ban dirinya sendiri dari UI.
