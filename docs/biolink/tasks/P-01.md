# P-01 — Optimasi muatan halaman publik (prefetch & font)

**Prioritas:** 🟡 P2 · **Estimasi:** kecil
**Commit dipecah dua:** `perf(biolink): P-01a limit vite prefetch to signed-in users` lalu `perf(ui): P-01b trim google font variants`

## Latar belakang (hasil ukur Review #5, `/@eidoertachta`, 360px)
- LCP 2,05 s (cache dingin, tanpa throttling) — masih di bawah target 2,5 s, tetapi muatan halaman terlalu berat untuk HP.
- `Vite::prefetch(concurrency: 3)` di `app/Providers/AppServiceProvider.php` membuat **setiap** halaman — termasuk halaman bio publik yang dibuka tamu dari Discord/WhatsApp — mengunduh **40 file JS ≈ 1 MB** (OfficerManagement, Clipper, Dashboard, Multiview, FAQ, …) setelah `load`.
- Google Fonts memuat 15 varian sebagai stylesheet render-blocking: Plus Jakarta Sans 400–700 **+ italic 400–700**, JetBrains Mono 400–700, Rajdhani 500–700. Padahal kode memakai `italic` hanya 14×, sementara `font-extrabold` (800) 20× dan `font-black` (900) 85× **tidak dimuat** sehingga browser memalsukan tebalnya (synthetic bold).

## P-01a — Batasi prefetch
**File:** `app/Providers/AppServiceProvider.php`, `app/Http/Middleware/HandleInertiaRequests.php`

1. Hapus `Vite::prefetch(concurrency: 3);` dari `AppServiceProvider::boot()`.
2. Di `HandleInertiaRequests::handle()` (override, panggil `parent::handle()` setelahnya) — atau di `share()` — aktifkan prefetch **hanya** bila:
   - user sudah login (`$request->user() !== null`), **dan**
   - route **bukan** halaman publik ringan: `bio.show` (`/@{slug}`) dan `bio.go` (`/go/{link}`).
   ```php
   if ($request->user() && ! $request->routeIs('bio.show', 'bio.go')) {
       \Illuminate\Support\Facades\Vite::prefetch(concurrency: 3);
   }
   ```
   (Tidak ada perubahan perilaku lain; user login tetap mendapat navigasi cepat.)

**Test** — `tests/Feature/BioLink/PublicPayloadTest.php`:
- Tamu `GET /@{slug}` → HTML **tidak** memuat skrip prefetch Vite (cari penanda yang dihasilkan `Vite::prefetch`, mis. `rel="prefetch"` / `window.addEventListener('load'` di skrip prefetch — periksa output sekali lalu pakai penanda yang stabil).
- User login `GET /@{slug}` → tetap tanpa prefetch.
- User login `GET /dashboard` → prefetch ada.
- Bila test gagal karena manifest Vite tidak ada di lingkungan test, tandai test dengan pengecekan `file_exists(public_path('build/manifest.json'))` → `markTestSkipped`, dan catat di Dev Notes.

**Uji manual:** buka `/@{slug}` sebagai tamu (mode incognito, build produksi) → DevTools Network: jumlah file JS turun dari ±40 menjadi ±3 (app, BioLink, vendor bila ada). Catat angka sebelum/sesudah di Dev Notes.

## P-01b — Rapikan varian font
**File:** `resources/views/app.blade.php` (link Google Fonts ±baris 59)

Ganti URL font menjadi:
```
https://fonts.googleapis.com/css2?family=JetBrains+Mono:wght@400;500;600;700&family=Plus+Jakarta+Sans:ital,wght@0,400;0,500;0,600;0,700;0,800;1,400&family=Rajdhani:wght@500;600;700&display=swap
```
- Plus Jakarta: buang italic 500/600/700 (cukup italic 400), **tambah 800** agar `font-extrabold` asli.
- `font-black` (900) tidak tersedia di Plus Jakarta Sans → jangan tambah apa pun; pemakaian `font-black` akan dipetakan ke `font-extrabold` saat migrasi UI Kit (cukup catat, **jangan** mengubah file `.vue` di task ini).
- Tambahkan `<link rel="preload" as="style" href="(URL yang sama)">` tepat sebelum link stylesheet.

**Uji manual:** halaman `/@{slug}` dan Dashboard tampil sama (judul, label mono, teks miring yang ada); DevTools Network → jumlah file font turun. Catat di Dev Notes.

## Di luar cakupan
- Inertia SSR untuk `/@{slug}` (opsi jangka menengah; dibuat task terpisah bila LCP produksi > 2,5 s di PageSpeed Insights).
- Teks < 11px & tombol kecil di halaman bio → dikerjakan saat migrasi halaman Bio-Link ke UI Kit (backlog `docs/ui/TASKS.md`).
